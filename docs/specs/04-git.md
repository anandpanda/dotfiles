# Phase 4: Git workflow

Date: 2026-10-28
Status: approved by Anand (picks closed in conversation)

## Purpose

Git the way a senior engineer has it set up: modern defaults, readable diffs,
verified commits per identity, a terminal client, GitHub CLI with two
accounts, worktrees made trivial, and a light commit-message convention.
Builds on the Phase 1 `git` and `ssh` modules; the identity split by
directory is unchanged.

## Modules

**git** (extends Phase 1)
- `home/.gitconfig`: identity includes (unchanged) plus the defaults: column,
  branch/tag sort, histogram diff, colorMoved, mnemonicPrefix, renames,
  push simple/autoSetupRemote/followTags, fetch prune/pruneTags/all,
  help autocorrect prompt, commit verbose, rerere enabled/autoupdate,
  rebase autoSquash/autoStash/updateRefs, merge conflictstyle zdiff3, pull
  rebase, core pager delta, interactive diffFilter delta, delta section,
  `core.hooksPath ~/.config/git/hooks`, `gpg.format ssh`, `commit.gpgsign`,
  `tag.gpgsign`, `gpg.ssh.allowedSignersFile` (state dir), aliases.
- `config/identity.personal`: adds `user.signingkey ~/.ssh/id_ed25519_personal.pub`.
  The overlay's `identity.work` adds the work key the same way.
- `config/hooks/commit-msg`: rejects a first line not matching
  `^(feat|fix|docs|style|refactor|perf|test|build|ci|chore|revert)(\(.+\))?!?: .+`
  unless it is a merge, revert, fixup or squash message. Prints the rule.
- `~/.local/state/git/allowed_signers`: generated by `install.sh` from the identity
  emails and public keys present on the machine (personal always, work when
  the key exists), so `git log --show-signature` verifies locally.
- `install.sh`: writes `allowed_signers`; idempotent.
- `doctor.sh`: signing key file exists for each identity; hooks path linked;
  `allowed_signers` current.
- `Brewfile`: `git`, `git-delta`, `difftastic`.
- `shell.zsh`: `gwt`, `gwtl`, `gwtr`, `lg` alias (lazygit lives in its module
  but the alias is here so git-centric shell bits stay together).
- `CHECKLIST.md`: add each public key on GitHub as a *signing* key too.

**lazygit**: `Brewfile`, `config/config.yml` (Catppuccin Mocha, delta pager,
nerd font icons, `os.editPreset: vscode`), `README.md` with the ten keys worth
knowing.

**gh**: `Brewfile`, `config/config.yml` is NOT linked (gh writes hosts and
tokens there); instead `install.sh` sets aliases via `gh alias set` idempotently
and `shell.zsh` adds a `chpwd` hook that runs `gh auth switch --user <acct>`
when crossing between `~/personal` and `~/work`, reading the account names
from `~/.config/dotfiles/gh_personal` and `gh_work` (remembered by preflight).
`preflight.sh`: if the personal account is not logged in, run `gh auth login`
(interactive) and remember the username; the work account likewise when the
profile is work. No terminal: print the commands and continue.
Aliases: `pc` (`pr create --fill --web`), `pv` (`pr view --web`), `co`
(`pr checkout`), `pm` (`pr merge --squash --delete-branch`), `prs`
(`pr list --author @me`), `runs` (`run list --limit 5`).

## Git aliases (in .gitconfig)

`st` status -sb, `co` checkout, `sw` switch, `br` branch, `ci` commit,
`amend` commit --amend --no-edit, `undo` reset --soft HEAD~1, `wip` add -A &&
commit -m "wip", `lg` log --graph --oneline --decorate -20, `lga` same for
all branches, `pushf` push --force-with-lease, `dft` difftool with
difftastic, `rank` shortlog -sn.

## Testing

- `.gitconfig` parses (`git config --file ... --list`), every alias resolves.
- commit-msg hook: accepts `feat: x`, `fix(scope)!: y`, merge and fixup
  messages; rejects `update stuff` and empty; exit codes and message text.
- allowed_signers generated correctly with 1 and 2 keys; rerun identical.
- In a temp repo under a fake `~/personal`: commit is signed with the personal
  key and `git log --show-signature` verifies against allowed_signers.
- lazygit config parses (`lazygit --config` dump or YAML check); gh aliases
  set idempotently with a fake `gh`; the chpwd hook switches with a fake `gh`.
- On this Mac: `git lg` colours, `git diff` through delta, a signed commit
  shows "Good signature", `lg` opens, `gh auth status` shows both accounts.
