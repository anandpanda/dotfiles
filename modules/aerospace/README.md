# aerospace

Tiling window manager. Alt-h/j/k/l focus, Alt-Shift-h/j/k/l move, Alt-1..9
workspaces, Alt-Shift-1..9 send a window there, Alt-Tab previous workspace,
Alt-f fullscreen, Alt-/ tiles, Alt-, accordion, Alt-Enter new Ghostty,
Alt-- / Alt-= resize. Alt-Shift-; enters service mode: Esc reload config,
r reset layout, f toggle float. Finder, System Settings and the menu bar
apps float. Not for you? Remove "aerospace" from the profile; Raycast still
snaps windows.
