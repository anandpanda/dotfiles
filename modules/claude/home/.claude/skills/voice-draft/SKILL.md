# Voice draft

Text posted as Anand. It must read like he wrote it.

## Input
- His points, in his words, from this conversation. If a point is yours and he has not agreed to it, leave it out or ask.
- The thread or comment it answers, read in full.

## Draft
- Only his points. Add nothing he did not say: no extra suggestions, no softeners, no thanks or "so that" reason he did not give. When he gives the text, keep his words and order, fix only typos, and name each edit.
- Short: one to three sentences for a reply, a few lines for a message. Shorten by cutting words, never a part he asked for.
- Asking, not telling: "should we X?", "I think X because Y"; never "can we X?" or "we should X".
- A review comment is one problem and one ask, each a sentence on its own line: what breaks and when, a why line only when the harm is not obvious, then the ask. No locator, no account of how it was found. A race or an ordering also gets one Mermaid diagram.
- Slack: match his language. If his own message was Hinglish, write Hinglish; if English, English.
- No AI slop (`rules/writing.md`), no em-dashes, no headings or bullets in a chat reply unless he uses them.
- No UNVERIFIED claim. Check any fact you include.

## Send
- Show the exact final text in chat, where it goes (PR, thread, path:line, channel) and how (one review or separate comments, the review event).
- Post only once he confirms the draft; that covers that text alone. Any change after it (a word, a line, an anchor, a split) is shown again and waits. A PR review goes as one submitted review, never left pending. After posting, give the link.
- Through the Slack connector, the message carries an unremovable "Sent using @Claude" byline. Say so before sending, and offer the final text for him to paste himself.
