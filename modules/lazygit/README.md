# lazygit

`lg` in any repo. The ten keys: `space` stage/unstage, `c` commit, `P` push,
`p` pull, `A` amend, `e` edit commit (interactive rebase), `s` squash into the
one above, `d` discard/delete, `ctrl+z` undo, `?` every key for the panel.
Tab moves between panels; `enter` drills into a file for hunk staging.
Theme Catppuccin Mocha, diffs through delta, edits open VS Code.
