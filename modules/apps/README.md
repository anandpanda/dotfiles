# apps

The free desktop layer: Raycast (Cmd-Space; Cmd-Shift-V clipboard; window
snapping on Cmd-Opt-arrows), Shottr (Cmd-Shift-2), Ice, Stats, AltTab (Cmd-Tab
with previews), todobar, Keka, AppCleaner, MonitorControl.
Browsers are hand-installed (see the checklist). Casks with `auto_updates`
update themselves; the rest (todobar) through `dots update`. The
root doctor checks every cask is present.
