# vscode

Settings, keybindings (defaults), tasks, snippets and the exact extension list.
install.sh links config/* into VS Code's user dir (differs per OS) and installs
missing extensions; doctor reports missing or extra ones; `dots vscode-prune`
removes extras. Settings Sync stays off: this repo is the sync.
Cmd-Shift-B on a .cpp file builds and runs it. Type `cp` + Tab for a contest template.
